# Flight to Freedom（中文版）錯誤修正指令

適用範圍：`Flight_to_Freedom-Grounding_zh/` 書本章節 ＋ 同資料夾的 `Flight_to_Freedom_101_Logbook.docx`

這份文件列出的都是**客觀錯誤**（事實錯誤或文本前後矛盾），不是文筆風格問題——不分讀者是誰都該修。以下 4 條已經在這個工作目錄裡的檔案上改好，這份文件是給 factory 那邊同步到他們自己的來源版本用的修改指令。每條都附原文、修改後、原因。

---

## 1. [110] SQUAWK 代碼位數不合規格

**檔案**：`110.txt`

真實世界的應答機 SQUAWK 代碼固定是 4 位數字，且只能用 0～7（八進制）。原稿把金額公式算出來的結果直接當 SQUAWK 代碼顯示，位數會隨金額變動，容易超過 4 位或出現 8、9。

**原文**（「兩個設計原則」段落最後）：
```
2. 「1.5 是「對齊餘裕 (Alignment Margin)」，不是收益預測。」...這組數字要能被你的神經系統接住，它才有作用。
```

**修改後**（在後面加第 3 條）：
```
3. 這是一個象徵性代碼，不是真實的航空應答機代碼。現實中的 Squawk 代碼是只使用 0～7 八進制數字組成的四位數字。你的應答機廣播代碼只是把上面算出的金額，寫成卡片上的一串數字做視覺化呈現，並不是用來輸入任何真實航空設備的代碼。
```

**原因**：不改變原本的金額計算或卡片呈現方式，只加一句澄清：卡片上的數字是象徵性的視覺呈現，不等於真實規格的航空電碼，讀者不會因為自己的金額位數不是 4 位而覺得「這裡設定錯了」。

## 2. [113] 121.5 MHz 被反覆說成「某座塔台專屬頻率」

**檔案**：`113.txt`

現實中 121.5 MHz 是全球共用的 VHF 守護／緊急頻率，由多個單位同時監聽，不是某一座塔台專屬的頻道。原稿裡「121.5 MHz」與「塔台」被反覆黏在同一個詞組或句子裡（例如「121.5 MHz 高維塔台對齊協議」），等於把頻率本身說成塔台的財產，這是事實錯誤。

**需要修改的 9 個位置**（原文 → 修改後）：

| 位置 | 原文 | 修改後 |
|---|---|---|
| 小節過渡句 | 並執行 121.5 MHz **高維塔台**對齊協定。 | 並執行 121.5 MHz **高維守護頻率**對齊協定。 |
| 協議說明 | 執行實體的「決策氣密室淨化」與「**高維塔台頻道**鎖定」協議。 | 執行實體的「決策氣密室淨化」與「**高維守護頻率**鎖定」協議。 |
| 協議說明 | 在 121.5 MHz 專用頻道完成與**高維塔台**的對齊。 | 在 121.5 MHz 專用頻道完成與**高維守護頻率**的對齊。 |
| 練習二標題 | [練習二] 內在練習：121.5 MHz **高維塔台**對齊協議 | [練習二] 內在練習：121.5 MHz **高維守護頻率**對齊協議 |
| Step 5 關鍵動作 | 直衝萬公尺高空中 121.5 MHz 的專用**高維塔台頻道**。 | 直衝萬公尺高空中 121.5 MHz **高維守護頻率的象徵性代表**。 |
| Step 5 關鍵動作 | 在心中聽見**塔台**清晰、溫暖的綠色共振回覆 | 在心中，**透過守護頻率**聽見清晰、溫暖的綠色共振回覆 |
| 段落收尾 | 並在 121.5 MHz 頻道完成了與**高維塔台**的對齊 | 並在 121.5 MHz 頻道完成了與**高維守護頻率**的對齊 |
| 夜間引導詞 | **高維塔台**的訊號此時已與你的心臟電磁場完美共振。 | **高維守護頻率**的訊號此時已與你的心臟電磁場完美共振。 |
| 術語表 | **高維塔台緊急頻率同步 (High-Dimensional Tower Emergency Frequency Sync)**：指調諧無線電旋鈕對準 121.5 MHz 專用甚高頻守護頻道...直接接通量子場宇宙**控制塔台** | **高維守護頻率同步 (High-Dimensional Guard Frequency Sync)**：指調諧無線電旋鈕對準 121.5 MHz 專用甚高頻守護頻道...直接接通量子場宇宙**的守護頻道** |
| 結尾段 | 與高維**控制塔台**完成了最精準的波頻共振 | 與高維**守護頻道**完成了最精準的波頻共振 |
| 結尾段 | **塔台**綠色訊號極度清晰 | **守護頻率**的綠色訊號極度清晰 |

**刻意不改的地方**（維持原樣，因為是故事裡的角色對白，不是在定義 121.5 MHz 這個頻率本身）：
- 開場故事裡的「高空管制塔台」「塔台導航聲音」「這裡是塔台」等對話
- 「夜間航線清理與高維塔台共振協議」這個小節標題（沒有跟 121.5 MHz 綁在同一句）

**原因**：守護頻率是真實存在的國際通用頻率，不屬於任何一座塔台；修正後「塔台」只保留在故事對白裡，不再被用來定義頻率本身的歸屬。

## 3. [109] 用真實診斷名稱當小說情節道具

**檔案**：`109.txt`

**原文**：
```
當建豪因為嚴重的慢性疲勞症候群而被迫休假三個月時，
```

**修改後**：
```
當建豪因為嚴重的過勞耗竭而被迫休假三個月時，
```

**原因**：「慢性疲勞症候群」是真實的醫學診斷名稱，用來當虛構角色的情節道具並不恰當，換成非診斷性的描述（過勞耗竭）即可保留原本的敘事效果。

## 4. Logbook（`Flight_to_Freedom_101_Logbook.docx`）同步修正

Logbook 裡對應的 2 類問題（SQUAWK 空格位數、121.5 MHz 塔台用詞）也要同步改，具體位置：

- **SQUAWK 填空卡**：`SQUAWK ＿＿＿＿＿＿`（6 個空格）→ `SQUAWK ＿＿＿＿`（4 個空格）；旁邊「應答機廣播代碼：＿＿＿＿＿＿ 元／月」的標籤改成「月度容量參考值：＿＿＿＿＿＿ 元／月」，避免美元金額被誤認成電碼本身。
- **121.5 MHz 塔台**：練習二標題「121.5 MHz 高維塔台對齊協議」→「121.5 MHz 高維守護頻率對齊協議」；檢查清單「綠色雷射射向 121.5 MHz 塔台」→「綠色雷射射向 121.5 MHz 高維守護頻率」；「塔台回覆（在心中聽見...）」→「守護頻率回覆（在心中聽見...）」。
- Logbook 是填空練習表，沒有轉述 109 章角色的故事情節，所以「慢性疲勞症候群」這條不適用於 Logbook。

## 不建議修改的部分（已評估過，刻意保留）
